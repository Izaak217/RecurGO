# Security reporting

English | [简体中文](SECURITY.md)

To report a possible vulnerability, use **Security → Advisories → Report a vulnerability** in the
repository if that option is available, or email
[izaak.zhang@outlook.com](mailto:izaak.zhang@outlook.com).
Do not post exploits, tokens, private game records, databases, logs, or local paths in a public issue.

A report can describe affected versions, reproduction conditions, possible impact, and a proposed fix.
The maintainer will assess the report before coordinating a fix and disclosure. No fixed response time is
promised here.

GitHub documentation: [privately reporting a vulnerability](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/report-privately).
