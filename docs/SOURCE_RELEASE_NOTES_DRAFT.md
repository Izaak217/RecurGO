RecurGO 是在本机使用 KataGo 的围棋打谱、对战和复盘程序。以下是早期拟发布的**源码预览**文案：
适合愿意自行准备 Python、KataGo 和显卡运行环境的使用者，不是双击即用的安装版。

## 本版可用功能

- 19 路新棋局、手动打谱，以及公平或辅助模式下的本机 AI 对战；支持执黑或执白。
- KataGo 当前局面候选点、胜率、目差、人类偏好、领地估计和规则说明。
- 可停止、可续做的全盘分析；胜率走势、着法质量、问题手、吻合度和概览视图。
- 本机棋谱库、自动保存、SGF 导入导出，以及本地图片静态局面识别。
- 默认英语、可选简体中文，保存语言设置后界面立即切换。
- 可选 Ollama 本机文字补充；不改变 KataGo 的落点或数值。
- 窄窗口使用原生白底溢出按钮查看放不下的工具栏项目，另保留 Menu / 菜单入口。

操作步骤见[用户使用说明](USER_GUIDE.md)；下载依赖和运行源码见
[从源码启动](SOURCE_SETUP.md)。许可、第三方组件与源码分发边界见
[分发说明](DISTRIBUTION.md)。

## 当前边界

- 已验证的开发环境是 Windows x64、Python 3.13 和 KataGo v1.16.5 CUDA 12.8 后端。
  其他硬件和干净电脑上的完整安装流程仍待验收。
- 源码包不含 KataGo 可执行文件、主模型、Human SL 模型、CUDA/cuDNN、Ollama、
  本机配置、个人棋谱、日志或缓存。使用者须按源码说明自行取得所需依赖。
- 正式 Windows 安装版尚未验收或发布；不要把 GitHub 自动生成的 Source code ZIP
  当成安装程序。
- 本机 AI 文字可能出错，模型是否稳定遵循所选语言仍需实际验证。

反馈普通问题时请提供可复现步骤、系统和显卡信息，并移除私人棋谱、数据库、日志中的
本机路径等个人资料。漏洞请按[安全报告说明](../SECURITY.md)私下联系维护者。
