# RecurGO 用户说明书（v1.0.1）

[English](USER_GUIDE.en.md) | 简体中文

本文说明 RecurGO 的日常操作。安装、下载、CUDA/cuDNN 配置和环境检测请看[Windows 安装指南](INSTALL_WINDOWS.md)；开发者从源码运行请看[源码启动说明](SOURCE_SETUP.md)。

## 三种常用操作

- **自己打谱或研究局面**：新棋局 → 手动打谱 → 在棋盘落子 → 按需开启实时分析。
- **与 AI 对弈**：新棋局 → 公平对战或辅助对战 → 选执色和难度 → 开始落子。
- **复盘已有棋局**：棋谱库或导入 SGF → 打开棋局 → 全盘 AI 分析 → 查看右侧图表。

## 启动与界面

从开始菜单或安装时选择创建的桌面快捷方式打开 RecurGO。首次使用前应按[安装指南](INSTALL_WINDOWS.md)通过独立的 KataGo 分析环境检测。更换显卡驱动、CUDA/cuDNN 路径或模型后，也应重新检测。

若 KataGo 配置不可用，棋盘和棋谱库仍可能打开，但 AI 对战、候选点和全盘分析不可用；请以检测工具的实际分析结果为准。

| 界面位置 | 用途 |
| --- | --- |
| 顶部工具栏 | 新棋局、棋谱库、悔棋、停一手、分析、导入导出等操作，以及模式、难度、执色和分析开关。 |
| 工具栏右端白底按钮 | 窗口变窄时展开未显示的工具栏项目。 |
| 左上角 Menu / 菜单 | 棋局、对战、分析和设置的备用入口，与工具栏使用同一状态。 |
| 中央棋盘及下方导航 | 落子；复盘时按首手、上一手、滑杆、手数框、下一手或末手跳转。 |
| 左侧说明 | 当前候选手的规则说明；启用 Ollama 后可查看补充文字。 |
| 右侧分析与复盘 | KataGo 状态、候选点，以及全盘复盘图表。 |

## 开始一盘棋

1. 点击 **New game / 新棋局**，输入棋谱名；黑方和白方姓名可以留空。
2. 选择模式，再点击确定。**Manual study / 手动打谱**可自行记录双方落子。
   **Fair play / 公平对战**与本机 AI 对弈，实时分析和领地显示会禁用；
   **Assisted play / 辅助对战**与本机 AI 对弈，可按需开启实时分析。
3. 对战模式可选执黑或执白及难度。执白时 AI 先行。入门至顶级使用 Human SL
   的不同人类棋风档位；**Strongest / 最强**使用主模型搜索后的最佳手。
4. 点击棋盘合法交叉点落子。轮到 AI 时请等它完成；每手棋自动写入本机棋谱库。

顶部模式、难度、执色控件也能修改当前棋局；全盘分析期间这些控件会暂时禁用。
**Undo / 悔棋**和 **Redo / 前进**可返回或重走棋步；对战模式会一并处理相应的 AI 手。
**Pass / 停一手**可停一手。双方连续停一手后会打开数子界面；也可点
**Finish / Score / 结束/数子**手动进入。

数子界面载入当前局面的 KataGo 实时领地，作为初始归属。用户可在下拉选项中选择
**归黑方**、**归白方**、**双方各半**或**待确认**，再逐点修改；选择
**标记／恢复整块死子**后，点击整块棋可标记或恢复死子。计分以用户核对后的归属为准。

根据中国围棋规则，双方共有的空点每方计半子。空心小方框表示待确认点，不会自动按
共有计算。确认按钮上方会显示剩余点数和处理方法；全部点位确认后才能结束对局。
如果当前局面没有实时领地数据，可返回棋局，在允许实时分析的模式中开启领地显示并
等待分析，或手动指定全部点位。数子窗口不会借用其他手数的领地，也不会另开一次分析。

死子默认隐藏；勾选 **Show dead stones / 显示死子**可淡化显示原位置，不影响计分。
**撤销全部点位修改**会恢复打开窗口时的归属。核对后点击确认，归属、死子标记和结果
会保存到棋谱库，再次打开时可查看；结果也会写入之后导出的 SGF。
**Resign / 认输**会先要求确认。新建棋局不会删除旧棋谱。

## 分析当前局面

配置好 KataGo 后，勾选 **Real-time analysis / 实时分析**。右侧候选表显示
候选点、人类偏好、胜率、目差和计算量；点击候选手可在左侧查看说明。搜索进行中数值
可能变化。**Ownership / 领地**可在棋盘上显示领地估计。公平对战模式中这两个开关不可用。

在 **Analysis settings / 分析设置**可修改实时分析与全盘复盘的每局面 visits，
初始值为 800。提高访问量通常需要更久；降低访问量可能使搜索不充分。
该设置不改变对战中“最强”AI 的搜索配置；旧访问量的缓存也不会当作新访问量结果。
不要把某个 visits 数值理解成适合所有棋局和电脑的“最强”标准。

## 打开棋谱与全盘复盘

点击 **Game library / 棋谱库**，可按棋谱名、棋手、日期、结果或模式搜索。
选中后点 **Open game / 进入棋谱**，或双击棋谱。未结束的对战会询问是
**Continue playing / 继续对弈**还是 **Review only / 仅复盘**。棋谱库还可修改
名称和棋手信息；删除会永久移除该棋谱、全部分支和关联复盘数据，且不能撤销。

打开历史棋谱后，使用棋盘下方的按钮、滑杆或手数框逐手查看。点击
**Analyze full game / 全盘AI分析**开始复盘；按钮随后可用于停止。已完成局面的
分析会保存，再次点击可继续未完成部分。复盘区域提供胜率走势、着法质量、问题手、
吻合度和概览；**Scope / 范围**可选全盘、布局、中盘或官子。问题手及吻合度图中的
标记可点击跳转对应局面。复盘评价是分析结果，不等于客观无误的棋理结论。

## 导入、识图和导出

- **Import SGF / 导入 SGF**：导入棋谱并保存其变化分支与注释，然后进入复盘。
- **Recognize image / 图片识谱**：从剪贴板粘贴或选择本地图片，必要时选路数、
  旋转、镜像或手选四角，检查并逐点修正识别结果，再指定当前黑方或白方落子。
  它创建静态局面，不会还原图片中看不到的历史手顺、提子数或劫争历史。
- **Export SGF / 导出 SGF**：把当前棋局导出为 `.sgf`。导出文件可能含棋手姓名、
  注释和结果，分享前请自行检查。

图片识谱在本机完成，不上传图片。

## 语言、外观与本机 AI 文字

打开 **Preferences / 偏好设置 → Language / 语言**，选择 English 或简体中文并
点击确定，界面会立即切换。新安装默认英语；用户输入的棋谱名和棋手名保持原文。
同一对话框还可调整棋盘、棋子、声音和音量；工具栏的 **Mute / 静音**可快速切换声音。

程序自带的规则说明不需要 Ollama。可选 Ollama 只补充本机文字解释，不决定落点或
KataGo 数值。按[Windows 安装指南](INSTALL_WINDOWS.md)准备可选服务和模型，再在
**Local AI explanation settings / 本机 AI 解释设置**中启用并选择模型。
语言模型可能出错，所选语言也不能保证它每次都严格遵循；落点与数值以 KataGo 为准。

## 本机数据、备份与卸载

安装版默认把棋谱、设置、分析缓存和日志保存在 `%LOCALAPPDATA%\RecurGO`。
可用 `RECURGO_DATA_DIR` 指定其它数据目录。
反馈问题时请先移除私人棋谱、
姓名、数据库、日志中的本机路径和其他个人信息；安全问题请按[安全报告说明](../SECURITY.md)
私下提交。

完整备份前先关闭 RecurGO，再复制上述数据目录；其中可能含私人棋谱、姓名、分析缓存、
环境路径和可选下载的 Ollama 模型。若只需分享单盘棋，可用 **Export SGF / 导出 SGF**，
并检查导出内容。卸载安装版不会自动删除独立的用户数据目录；重装或更新程序也不会把
该目录当成程序文件覆盖。

## 常见问题

| 情况 | 先检查 |
| --- | --- |
| 没有候选点 | 是否已勾选实时分析、是否处于公平对战；再运行独立环境检测并看 KataGo 状态。 |
| AI 不落子 | 是否轮到 AI，以及独立环境检测是否真正完成分析；未配置引擎时 AI 不能走棋。 |
| 窄窗口找不到控件 | 点击工具栏右端白底溢出按钮，或使用左上角 Menu / 菜单。 |
| 图像识别有误 | 指定正确路数、手选四角，再逐点校正；识别结果需人工确认。 |
| Ollama 没有文字 | 先核对本机服务、模型和解释设置；不影响 KataGo 分析。 |

需要下载和配置细节时，请阅读[Windows 安装指南](INSTALL_WINDOWS.md)。
