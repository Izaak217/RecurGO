# RecurGO v1.2.0 更新说明

本次新增 **独立分析报告导出功能**。完成棋局分析后，可以将结果导出为一个 HTML 文件。报告自带交互界面，可使用浏览器（如 Edge、Chrome）打开。

本次同时提供 **TF3 版**和 **B28 版**，两版软件功能相同，均包含报告导出。TF3 版使用 KataGo 1.18.2 与 TF3 模型，B28 版使用 KataGo 1.16.5 与 B28 模型，可按需选择其中一个安装包。覆盖安装可切换版本，棋谱、设置和已有分析数据会保留；不同模型的分析结果分别保存。

报告包含：

- **逐手复盘**：查看每一手的棋盘，支持前后手、手数跳转、滑杆操作和已有变化分支。
- **候选与参考变化**：查看当前局面的候选落点、胜率、目差和访问量，并逐步回放已保存的候选变化。
- **全盘分析统计**：包含胜率走势、着法质量、问题手、吻合度和总览，支持按全盘、布局、中盘、官子筛选。
- **图表联动**：点击胜率曲线或问题手，可以跳转到对应局面。

报告支持中英文、电脑和手机布局，可以离线查看。

如果棋盘或按钮无法操作，请使用浏览器（如 Edge、Chrome）打开。如果使用浏览器打开后仍无法操作，请检查浏览器是否已开启 JavaScript。

报告保存的是导出时已有的分析结果，未分析或不完整的局面会明确标注。建议先完成“全盘 AI 分析”，再导出完整报告。
