# 首个公开 Windows 安装版的目标（发布前设计记录）

[English](RELEASE_TARGET.en.md) | 简体中文

这份文件保留首版发布前的设计目标与验收清单，不表示下面的每一项已在所有设备上验证。首个正式版本为
**v1.0.0**；此前的 `v0.2.0.dev30` 仅供内部测试。实际安装步骤、已验证范围及下载文件以安装指南和同版本 Release 为准。
与之对应的用户步骤见 [Windows 安装指南](INSTALL_WINDOWS.md)，日常操作见[用户说明书](USER_GUIDE.md)。

## 用户最终会拿到什么

GitHub 公开一份源码仓库。在同一个版本号的 Releases 中，另行上传一个 Windows x64
安装程序。GitHub 自动附带的 `Source code (zip/tar.gz)` 是该版本源码的快照，
不是第二套程序，也不能代替安装程序。安装程序从同一份源码构建，附带完成安装所需的
应用运行组件、KataGo 引擎、两个固定模型、分析配置、说明和适用的许可资料。

源码仓库不提交模型、运行库或开发者的 `runtime/`；这些固定资源只进入经过单独核对的
安装包。开发者本机的棋谱、数据库、缓存、日志、密钥和路径配置既不进源码，也不进安装包。
构建从干净的发布目录进行，不能直接压缩开发者当前工作目录。

## 安装后的预期行为

1. 用户运行安装程序，启动 RecurGO，无需自行安装 Python、Qt 或寻找 KataGo 模型。
2. 主程序不提供环境设置或独立预检入口，只读取独立工具保存的路径配置来启动引擎。
3. 随安装版提供独立的“检测分析环境”程序。它检查系统 NVIDIA 驱动和 KataGo 直接依赖的 Visual C++ 运行库，并优先从用户数据目录
   `%LOCALAPPDATA%/RecurGO/cuda_deps/nvidia/{cuda,cudnn}/bin` 自动寻找用户放入的运行库；
   用户仍可在其中选择非标准 CUDA/cuDNN 目录，
   首次配置后或环境发生变化时主动运行一次；
   它真正启动随包 KataGo 并分析测试局面，收到有效候选才报告“分析已就绪”。
   缺少依赖时给出缺失项及官方获取页面。日常打开主程序无需重复测试，也不规划自动重测按钮。
4. 正常进入现有棋盘、对战、实时分析、棋谱库、SGF 导入导出和全盘复盘。原有 KataGo
   主模型、Human SL 模型与推荐排序规则保持不变；右侧候选表等原有界面不因打包而重做。
5. 工具栏新增明确的“分析设置”入口，显示“每个局面的访问量（visits）”，默认 800。
   用户可自行输入访问量并保存；设置用于之后的实时分析和全盘复盘，历史缓存按访问量区分，
   已保存的旧结果不会被冒充为新预算的结果。调低访问量要明确提示搜索可能不充分。
   对战中的“最强”AI 仍使用独立的现有搜索预算；不能因分析设置而暗中变弱。
6. 棋谱、分析缓存和个人设置写入当前 Windows 用户的可写数据目录，而不是安装目录；
   更新程序不会覆盖个人数据，程序不会把这些数据上传到 GitHub。
7. Ollama 默认关闭，也不随安装包提供。用户若希望加入语言模型补充说明，从 Ollama
   官方来源自行取得 CLI ZIP 放入用户数据目录的 `ollama/`，或使用官方安装程序；
   模型由 Ollama 管理，然后在现有“本机 AI 解释设置”中启用。没有 Ollama 时，
   程序自带的即时棋理说明和所有 KataGo 功能仍可用。

## 首发支持边界

目标是 **Windows x64 + NVIDIA CUDA 12.8 后端**。开发机的 NVIDIA GeForce
RTX 5070 Ti Laptop GPU（约 12 GB 显存）已验证完整运行；另一台设备的
NVIDIA GeForce RTX 2080 Ti 已通过独立工具的实际 KataGo 分析，主程序也显示
候选点和胜率。后者尚未完成全部功能验收，且不能由两张显卡的结果推断所有
NVIDIA 显卡均可运行。
AMD、Intel、CPU 和其他 KataGo 后端不列为首版已支持项。NVIDIA 驱动、CUDA/cuDNN
由用户从官方来源按本机情况准备，不放进本项目安装包。约定的运行库目录位于当前用户可写的数据目录，
由独立工具直接打开，不要求普通用户修改程序安装目录。

默认 800 visits 只是当前项目默认值，不宣称是所有电脑或局面的“最强”标准。
搜索质量相关的修改仍须按项目基准验证，安装和可移植性工作不得削弱现有主模型或
把非最佳候选显示为“一选”。

## 发布前必须完成的验收

- 构建真正可运行的 Windows 安装程序；确定可执行文件、资源定位、本机依赖发现与用户数据目录。
- 实现并测试基础启动检查、独立环境检测和访问量设置，包括非标准安装路径、取消、重启和缓存区分。
- 用干净的 Windows 环境验证安装、真实 KataGo 分析、对局、SGF、全盘复盘与可选 Ollama。
- 核对安装包内每个第三方组件、模型及许可义务，保留必要的版权与对应源码获取方式。
- 对源码暂存内容和安装包内容分别做隐私检查；核对安装包大小、校验值和 GitHub
  Release 的单文件大小限制。

`v0.2.0.dev30` 开发版不安排单独公开。首版按同一 v1.0.0 版本提供源码与 Windows 安装包；仍需持续扩展不同电脑和功能的验证范围。
