# v1.0.1 中国规则数子设计与验证范围

核对日期：2026-09-30。按用户确认的方向实现；具体测试与发布状态见 [v1.0.1 验证记录](RELEASE_1.0.1.md)。

## 规则依据

- [中国围棋协会：中国围棋规则](https://wqwh.weiqi.org.cn/rules/)，第 7—9、11、20—21 条。
- [中华民国围棋协会刊载的规则文本](https://www.weiqi.org.tw/Weiqi/Bulletin/BulletinDetail?pmBType=5)，用于交叉核对上述数子、贴子和终局条款。
- [KataGo Analysis Engine 文档](https://github.com/lightvector/KataGo/blob/master/docs/Analysis_Engine.md)，用于区分 AI 归属预测与已确认的终局归属。

中国规则数活子和围住的空点；双方活棋之间的公用空点均分。双活中的专有眼位与共同空点要分别处理，不能把整个双活区域全部均分或全部不计。

普通劫争不对应固定的半子或四分之一子分配。未同意终局且有争议时应继续对局；双方已经同意终局而留下的可争点，按第 21 条的双活方式处理。多劫循环等特殊终局按适用规则另行处理，不把它们自动转成平分或和棋。

## 交互与数据

1. 当前节点的领地图只作初始预览；每次进入数子都重新完成一次分析，沿用现有分析设置和模型，不降低搜索质量。已保存的终局图直接只读展示。
2. 点位编辑提供四种明确状态：归黑、归白、双方各半、待确认。空点只是棋盘上没有棋子，不等于计分为零；“待确认”也不等于“双方各半”。
3. 保留逐点修改、颜色画笔、撤销修改和即时计数。共享点显示黑白各半标记；待确认点使用不同的标记，不能混淆。
4. AI 归属是预测值。绝对值低于 0.9 的点列为待确认；0.9 是人工复核的界面启发阈值，不是规则、概率保证或死活证明。局内渲染阈值保持不变。已知当前劫点强制待确认；并不声称识别全部历史劫争和循环。
5. 活棋本身计给本方，死棋在规则计数前确认移除。共有只适用于合法的共有空点；校验棋块死活与逐点归属是否冲突，避免棋子被重复计数或活子被均分。
6. 所有点位确定、死活无冲突后，用户确认终局。保留待确认点时只能查看暂算与返回对局，不能保存成确定胜负。对双方约定终局后保留的争点，允许明确标为双方各半。

## 精确计数

设黑方独占点数为 B、白方独占点数为 W、共有空点数为 S：

- 黑方总子数 = B + S / 2。
- 白方总子数 = W + S / 2。
- 19 路终局在全部点位归属确定后，双方总子数之和为 361。
- 黑贴 3¾ 子时，黑方胜差（子）= 黑方总子数 − 180.5 − 3.75。
- 与引擎使用的 7.5 点贴目对应：胜差（子）=（黑方总子数 − 白方总子数 − 7.5）/ 2。

例如 B=184、W=176、S=1，则双方分别为 184.5、176.5 子，黑胜 ¼ 子。
内部以半点整数计数，并准确处理贴目；不累加二进制浮点误差，也不提供任意“¼目归属”来代替规则。

把之前的所有“中立点”机械地各分一半，只会同时增加双方总数，不改变胜差，不能解决把大片未围严领地误判为中立的问题。修复仍以复用正确的 KataGo 归属、允许核对修正为核心。

## 联动范围

- 计分模型：保存黑、白、共有、待确认四种状态，区分预测与确认，校验总数与死活一致性。
- 棋盘与终局窗口：逐点编辑、共享和待确认标记、即时重算及确认条件。
- 主窗口与引擎：复用同节点数据；过期请求、关闭、取消及重新打开不覆盖手动编辑，也不触发额外落子。
- 本地存储：保存最终点位归属和结果，重新打开仍可查看；旧棋谱保持兼容。
- SGF：核对结果数值单位与导出兼容性，不把中国规则的胜差“子”与引擎点数混用；不擅自重写旧棋谱。
- 文档与发布：双语更新说明、规则来源、用户操作、升级和发布步骤，以及如实记录的验证范围。

## 回归验收

- 常规封闭终局、死子移除、两眼活棋。
- 无眼双活、带专有眼位的双活、奇数与偶数个共有点。
- 未结束劫争、已确认终局后的剩余争点、循环劫争不被自动平分。
- AI 接近零但实际仍有争议的点，不能自动当作共有。
- 黑／白／共有／待确认逐点切换，半子总数与四分之一子胜差、不同贴目。
- 黑白总数、共有点和棋盘总点数的守恒；不重复计算棋子与领地。
- AI 刷新保留人工修改，错误节点与过期回包被拒绝，关闭和重新打开安全。
- 确认、返回继续下、重新加载、旧数据库、SGF 导出及中英文界面。
- 引擎配置、模型和现有客观分析搜索预算保持不变；真实引擎和最终安装包分别验证。

## 当前状态与后续顺序

实现、规则回归、真实引擎验证、界面检查、安装包清单审计完成后，才提交源码并发布同版本安装程序与 SHA-256。远端标签、附件状态和摘要须另行核验。

本功能是人工确认的数子工具，不是自动裁判。未终局的预测仍可能出错，特殊循环须按比赛规则处理。数据库和 SGF 结果沿用项目既有的中国数子胜差单位（子），不批量解释或改写历史结果；本地逐点修正图保存在棋谱库中，SGF 导出保留结果但不附带这张修正图。
